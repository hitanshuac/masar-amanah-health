# Hack2Skill & GITEX 2026 Competition Governance

1. **Zero-Friction Judge Evaluation:** Every new feature must be testable by a competition judge in ≤3 clicks without requiring an API key, login, or external file download.
2. **Auditability & Evidence:** Every clinical or architectural claim in documentation must link to a verifiable file path and requirement ID (`PM-n`, `UX-n`, `ENG-n`, `RES-n`).
3. **Regional Alignment:** All care routing, terminology, and interoperability features (HL7 FHIR R4 / Malaffi) must align with Department of Health (DoH) Abu Dhabi and SEHA standards.
